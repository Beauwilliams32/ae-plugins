# Capability contract per effect

GENERATED by `tools/decode-flags.mjs` from `specs/*.json`. Do not edit.

`eGLO`, `eGL2` and `eINF` are the PiPL atoms AE's host reads to decide *how* to
call an effect. They are a contract, not a description: each named flag below is
an obligation the render path has to meet. See `plugins/LUTBlend/README.md` for
what happens when one is claimed and not honoured — LUTBlend shipped with three
of these invented rather than recovered.

## Obligations across the fleet

| Obligation | Effects | Consequence for a rebuild |
|---|---|---|
| `PF_OutFlag_DEEP_COLOR_AWARE` | 16/16 | a **16-bit** render path is required |
| `PF_OutFlag2_FLOAT_COLOR_AWARE` | 4/16 | a **32-bpc float** render path is required |
| `PF_OutFlag2_SUPPORTS_SMART_RENDER` | 4/16 | a `PF_Cmd_SMART_RENDER` handler is required |
| `PF_OutFlag2_SUPPORTS_THREADED_RENDERING` | 16/16 | shared render state must be thread-safe |

**Float-capable:** BeatGridRuler, BeatSnap, MotionCurveX, ShakeCapture — these cannot share a render
path with the 8/16-bit effects.

**Smart-render:** BeatGridRuler, BeatSnap, MotionCurveX, ShakeCapture — these need a
`PF_Cmd_SMART_RENDER` handler, which is a substantially larger piece of
host integration than a plain `PF_Cmd_RENDER` path.
