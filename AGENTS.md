## What this repo is

An After Effects C++ plugin fleet recovered from **shipped compiled binaries**. 16 effects, 15
with a recovered source namespace, 1 (MotionCurveX) with none. `src/<ns>/` is the recovered
source; `specs/` and `PARAMETERS.md` describe the wiring; `RECOVERY-STATUS.md` is the measured
coverage table.

## Gate

```bash
npm run check   # node --check over tools/, tools/demo/ and test/
npm test        # node --test test/*.test.mjs  (92 tests)
npm run status  # re-measures recovery coverage (tools/codegen-diff.mjs)
```

`npm test` compiles the recovered namespaces with `clang++` and compares instruction sequences
against the shipped bundles, so it needs the bundles present and takes a few seconds per
namespace. It also fails if `RECOVERY-STATUS.md` no longer matches a fresh measurement.

This file states what is true of **this repo**. The After Effects domain knowledge that

## Rules that exist because something went wrong

- **Never delete an installed bundle and never touch `.install-backups`.** On 2026-10-13 an
  installer path was pruned and the fleet had to be recovered from the installed copies
  (`../docs/INCIDENT-2026-10-13-accidental-project-deletion.md`). The 16 installed bundles under
  `/Applications/Adobe After Effects 2026/Plug-ins/` and the root-owned `.install-backups` are
  **the only remaining artefacts of the shipped binaries**; reading them is fine, removing them is
  not. Installing or reinstalling needs administrator rights — an owner action.
- **No host claim without a host run.** No AE host has loaded a rebuilt bundle
  (`RECOVERY-STATUS.md`, "What this document does NOT measure"). A green gate is not host
  acceptance; the host-acceptance packet's boxes stay blank until someone ticks them in After
  Effects.
- **The AE SDK is never committed.** Headers live outside the repo; nothing under `src/` may vendor
  them (`test/` fails on SDK paths appearing in tracked files).
- **No cloud generative media.** The theme and the demo harness are local; the brand palette comes
  from `brand/tokens.css`, never from a network fetch at build time.
- **Archive, never delete.** Retired work goes to a dated `archive/` path or a
  `archive/<branch>-<yyyymmdd>` tag with a stated reason; only Beau deletes.

## Layout shortcuts

`src/` recovered namespaces · `test/` node:test suites (one per namespace plus brand, build,
specs, docs) · `tools/` recovery tooling (`recover`, `codegen-diff`, `render-specs`,
`recovery-status`) · `tools/demo/` the local C++ demo harness that renders panels from the
recovered code · `plugins/<Name>/` per-plugin PiPL and CI notes · `specs/` generated parameter
specs · `packaging/` ZXP notes (signing is owner-gated).
